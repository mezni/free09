
# Contributing to telco-si

## Development Rules

1. Use `uv` to manage Python dependencies.
2. Add tests for new behavior.
3. Run `uv run pytest` before committing.
4. Run `uv run ruff check .` before committing.
5. Never commit real credentials or secrets.
6. Update `LOG.md` after completing each development step.
7. Keep generated telecom data synthetic and reproducible.
8. Use descriptive Git commit messages.
