# build-phase3: Configuration Contract

## OpenAPI Specification Contract

### Specification File
- **Path**: `services/auth-service/openapi/person-management.yaml`
- **Version**: 3.1.0
- **Format**: OpenAPI 3.1 YAML
- **Generated**: By `make sdk` (see quickstart.md)

### SDK Generation Contract
- **Python SDK**: `services/auth-service/sdk/person_api.py`
  - Generated by: `openapi-generator generate -i openapi/person-management.yaml -g pydantic -o sdk/`
  - Must produce: Type-safe models, async client, Pydantic v2 validation
- **TypeScript SDK**: `services/crm-service/sdk/person-api.ts`
  - Generated by: `openapi-generator generate -i openapi/person-management.yaml -g typescript-axios -o sdk/`
  - Must produce: Axios-based client, TypeScript interfaces, request validation

### Validation Middleware Contract
- **Path**: `services/common/middleware/validation.py`
- **Input**: Pydantic BaseModel from SDK
- **Output**: 400 Bad Request with structured error JSON
- **Coverage**: 100% of OpenAPI request bodies

### Response Transformation Contract
- **Path**: `services/common/transformers.py`
- **Input**: Database model / ORM result
- **Output**: Canonical API response format
- **Must include**: camelCase conversion, field whitelisting, meta headers

### Gateway Contract
- **Path**: `deploy/compose/traefik.yaml`
- **Rate Limit**: Per-endpoint, per-API-key
- **Auth**: OAuth2.1 bearer token validation
- **Health**: `/healthz` endpoint, no auth, simple uptime check
