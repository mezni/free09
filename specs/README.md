# Feature Specifications

Create one directory per cohesive feature:

```text
specs/
├── authentication/
│   ├── spec.md
│   └── tasks.md
├── crm-subscribers/
│   ├── spec.md
│   └── tasks.md
├── catalog-subscriptions/
├── devices-sims/
├── provisioning/
├── invoices/
├── payments/
├── ledger/
├── credit-memos/
└── synthetic-data/
```

Do not mark a spec Approved until scope, business rules, permissions, failure paths, and acceptance criteria have been reviewed. Keep task plans derived from the approved specification.
